# Mystic Fog Maze

A casual puzzle game where the player navigates through endless mazes surrounded by a mysterious fog. 

---

## About

This repository contains the source code (v1.0) of the game.

---

## Installation

```bash
git clone https://github.com/AntonisDevStuff/mystic-fog-maze-src.git
cd mystic-fog-maze-src
pip install -r requirements.txt
```

---

## Running the game

```bash
python main.py
```

## Assets

> ⚠️ **The source code is open source. The assets are not.**

All assets from the game are **proprietary** and
remain the property of their respective creators.

This means:

- If you clone this repository, **the game will not run**.
- You must **supply your own assets** matching the layout in
  [`Assets`](assets/README.md).
- You may **not** redistribute, modify, or reuse the original assets without
  permission.

If you want to run the game, you will need to
replace the assets with placeholders of the same filenames and dimensions.
